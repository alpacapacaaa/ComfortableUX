# ComfortableUX

**모두가 원했던, 가장 편안한 사용자 경험.**

복잡한 확인 절차, 성가신 보안 팝업, 여러 번 눌러야 하는 동의 버튼 — 이제 다 필요 없습니다.
ComfortableUX는 사용자가 아무 고민 없이, 아무 저항 없이 다음 화면으로 매끄럽게 넘어갈 수 있도록
설계된 인터페이스 모음입니다. 클릭 한 번, 스와이프 한 번마다 고객님이 원하시던 바로 그 경험을
드립니다. 저희가 지향하는 건 오직 하나, "편안함"입니다.

...그런데 이상하게 너무 편안하다.

실은 ComfortableUX는 실제로 있을 법한 프로덕션 화면을 그대로 재현한 뒤, 그 "편안함" 안에
보안 취약점 또는 UX 다크패턴을 정확히 하나씩 심어 넣는 목업 시리즈다. Instagram Reels용 화면
녹화 콘텐츠로 제작하며, 컴포넌트 라이브러리가 아니라 "실제로 존재하는 서비스"처럼 보이는
완성된 화면을 만드는 데 집중한다. 멀쩡하고 신뢰가 가는 화면일수록 뒤통수는 더 크게 돌아온다.

## 원칙

- **보안 취약점**과 **UX 다크패턴**을 모두 다룬다. 어느 한쪽으로 국한하지 않는다.
- 폼팩터는 고정하지 않는다. 패러디 대상이 모바일 앱이면 모바일로, 데스크톱 웹 서비스면 데스크톱으로.
- 기준은 하나: "이거 실제로 있을 법한데?"라는 리얼함과 "이거 뭐야 실화냐"라는 황당함, 그 사이 가장 아슬아슬한 지점.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript |
| 스타일링 | Tailwind CSS |
| 모션 | Framer Motion |
| 상태 관리 | React 기본 훅 (useState / useReducer) |
| 패키지 매니저 | pnpm |
| 배포 | Vercel |

실무에서 널리 쓰이는 조합으로만 구성해 포트폴리오에 그대로 명시할 수 있게 한다.

## 프로젝트 구조

```
app/
  layout.tsx           # 메타데이터, 폰트, 전역 배경
  page.tsx             # 시리즈 런처 (에피소드 목록)
  episode-1/
    page.tsx           # 에피소드별 상태머신 (화면 전환 orchestration)
    _components/       # 해당 에피소드 전용 컴포넌트
  episode-2/
    ...
components/
  ui/                  # 여러 에피소드에서 재사용하는 컴포넌트
    IntroBanner.tsx      # "ComfortableUX Presents" 스플래시 배너
    SubtitleOverlay.tsx  # 에피소드 마지막 화면 자막 placeholder
```

## 컨벤션

- 각 에피소드는 독립된 라우트로 구성한다 (`/episode-1`, `/episode-2`, ...)
- 각 에피소드 시작에는 "ComfortableUX Presents: [코드네임]" 스플래시 배너와 가짜 마케팅 카피를 넣는다
- 각 에피소드 마지막 화면에는 자막 placeholder 영역을 남긴다 (예: "OWASP Top 10 중 [카테고리]" 같은 텍스트를 편집 단계에서 삽입)
- 백엔드 없이 프론트 상태값만으로 인터랙션이 동작하면 충분하다 (실서비스 배포용 아님)

## 아이디어 후보

| 코드네임 | 대상 서비스 | 폼팩터 | 한 줄 훅 | 카테고리 |
|---|---|---|---|---|
| NOSY | 은행 앱 | 모바일 | 번호 하나만 바꿨을 뿐인데, 이웃집 계좌가 훤히 보인다 | 보안 (IDOR / OWASP A01) |
| ROACH | 피트니스 구독 앱 | 모바일 | 가입은 한 번, 해지는 여섯 단계 | 다크패턴 |
| SHADOW | 메신저 앱 | 모바일 | 지웠다고 믿었던 그 메시지, 서버는 기억하고 있다 | 프라이버시 |
| GATE | B2B SaaS 관리자 대시보드 | 데스크톱 | URL 끝자리만 바꿨을 뿐인데 옆 회사 데이터가 열린다 | 보안 (Broken Access Control) |
| FINE PRINT | 이커머스 체크아웃 | 데스크톱 | 결제 마지막 순간에야 등장하는 수수료 | 다크패턴 |
| GHOST | 쿠키 동의 배너 | 데스크톱 | "전체 동의"는 크고 밝게, "거부"는 어디 있는지도 모르게 | 다크패턴 |
| ECHO | 소개팅 앱 | 모바일 | "누가 봤는지" 알려주는 기능, 사실은 모두의 비공개 사진을 보여준다 | 보안 (IDOR) |
