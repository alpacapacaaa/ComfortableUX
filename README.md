# ComfortableUX

실제로 있을 법한 화면 속에 보안 취약점 또는 UX 다크패턴을 하나씩 몰래 넣어둔 목업 시리즈.
Instagram Reels용 화면 녹화 콘텐츠로 제작하며, 컴포넌트 라이브러리가 아니라 완성된 하나의
서비스 화면처럼 보이는 목업을 만드는 데 집중한다.

"Comfortable"이라는 이름 자체가 반어법이다 — 멀쩡하고 신뢰가 가는 화면일수록 뒤통수가 크다.

## 이 프로젝트가 다루는 것

- **보안 취약점**과 **UX 다크패턴**을 모두 다룬다. 어느 한쪽으로 국한하지 않는다.
- 폼팩터는 매번 고정하지 않는다. 패러디 대상이 모바일 앱이면 모바일로, 데스크톱 웹 서비스면
  데스크톱 화면으로 만든다.
- 목표는 "이거 실제로 있을 법한데?"라는 리얼함과 "와 이거 뭐야 실화냐"라는 황당함 사이의 균형.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript |
| 스타일링 | Tailwind CSS |
| 모션 | Framer Motion |
| 상태 관리 | React 기본 훅 (useState / useReducer) |
| 패키지 매니저 | pnpm |
| 배포 | Vercel |

실무에서 널리 쓰이는 조합으로만 구성해 포트폴리오에 그대로 명시할 수 있게 한다.

## 프로젝트 구조

```
app/
  layout.tsx           # 메타데이터, 폰트, 전역 배경
  page.tsx             # 시리즈 런처 (에피소드 목록)
  episode-1/
    page.tsx           # 에피소드별 상태머신 (화면 전환 orchestration)
    _components/       # 해당 에피소드 전용 컴포넌트
  episode-2/
    ...
components/
  ui/                  # 여러 에피소드에서 재사용하는 컴포넌트
    IntroBanner.tsx      # "ComfortableUX Presents" 스플래시 배너
    SubtitleOverlay.tsx  # 에피소드 마지막 화면 자막 placeholder
```

## 컨벤션

- 각 에피소드는 독립된 라우트로 구성한다 (`/episode-1`, `/episode-2`, ...)
- 각 에피소드 시작에는 "ComfortableUX Presents: [코드네임]" 스플래시 배너와 가짜 마케팅 카피를 넣는다
- 각 에피소드 마지막 화면에는 자막 placeholder 영역을 남긴다 (예: "OWASP Top 10 중 [카테고리]" 같은 텍스트를 편집 단계에서 삽입)
- 백엔드 없이 프론트 상태값만으로 인터랙션이 동작하면 충분하다 (실서비스 배포용 아님)

## 아이디어 후보

| 코드네임 | 대상 서비스 | 폼팩터 | 소재 | 카테고리 |
|---|---|---|---|---|
| NOSY | 은행 앱 | 모바일 | 이체확인증 ID만 바꾸면 남의 계좌가 보임 | 보안 (IDOR / OWASP A01) |
| ROACH | 피트니스 구독 앱 | 모바일 | 해지 버튼을 찾아 떠나는 로치모텔 다크패턴 | 다크패턴 |
| SHADOW | 메신저 앱 | 모바일 | 삭제한 메시지가 실제론 서버에 남아있음 | 프라이버시 |
| GATE | B2B SaaS 관리자 대시보드 | 데스크톱 | 다른 회사 계정 데이터가 URL 조작만으로 열람됨 | 보안 (Broken Access Control) |
| FINE PRINT | 이커머스 체크아웃 | 데스크톱 | 결제 마지막 단계에서만 드러나는 숨은 수수료 | 다크패턴 |
| GHOST | 쿠키 동의 배너 | 데스크톱 | "전체 거부"는 숨기고 "전체 동의"만 크게 보여줌 | 다크패턴 |
| ECHO | 소개팅 앱 | 모바일 | "누가 봤는지" 기능이 실은 남의 비공개 사진까지 노출 | 보안 (IDOR) |
